# AI ລະຄອນ Studio

ເຄື່ອງມືສ້າງ Master Prompt ສຳລັບເຮັດລະຄອນ AI ຄົບ 8 ຂັ້ນຕອນ ເປັນພາສາລາວ:
ພລັອດ → ຕົວລະຄອນ → ສາກ → ວິດີໂອ → ພາບແຕ່ລະຊີນ → ສຽງ ແລະ ບົດເວົ້າ → ຕັດຕໍ່ → ໂພສ.

ເລືອກຕົວເລືອກໃນໜ້າເວັບ, ກົດ "ຄັດລອກ Prompt" ແລ້ວນຳໄປວາງໃນ ChatGPT, Gemini, Claude ຫຼື Meta AI.

- ໜ້າເວັບໄຟລ໌ດຽວ (`index.html`), ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງ
- ເລືອກພາສາຂອງ Prompt ໄດ້: ລາວ ຫຼື English
- ການຕັ້ງຄ່າຖືກບັນທຶກໄວ້ໃນບຣາວເຊີຂອງແຕ່ລະເຄື່ອງ
